# Stack Technologiczny

## Frontend

- **Framework**: React 19 (TypeScript)
- **Zarządzanie stanem**:
  - Redux Toolkit + Redux Saga (główna logika aplikacji)
  - TanStack React Query (fetche danych, cache)
  - Context API (lekkie stany lokalne/UI)
- **Stylowanie**: Styled Components (+ polished, styled-normalize)
- **Routing**: React Router DOM 7
- **I18n**: i18next (obsługa języków: polski, angielski, niemiecki)
- **Drag & Drop**: @dnd-kit

## Backend / Integracje

- **Hosting**: Netlify
- **Serverless**: Netlify Functions
- **Baza danych**: MongoDB (Mongoose)
- **Real-time**: Ably (system powiadomień/synchronizacji)
- **Media**: Cloudinary (przechowywanie obrazów)
- **Auth**: GoTrue JS (Netlify Identity)
- **Inne**: EmailJS (wysyłka maili)

## Narzędzia Develperkie

- **Linter/Formatter**: ESLint, Prettier
- **Build Tool**: Netlify Dev / React Scripts
